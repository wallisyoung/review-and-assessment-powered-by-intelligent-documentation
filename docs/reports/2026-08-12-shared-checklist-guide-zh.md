# 共通检查列表使用指南（简版）

共通检查列表（例：登记类文件一致性审查）是声明了文件类型的共享 CheckListSet。**所有用户均可查看**，**编辑（创建/修改/删除）仅限管理员**。

---

## 1. 管理员：复制并调整共通检查列表

修改采用"复制既有集合、在新集合中调整"的流程。

### 步骤
1. 打开**检查列表一览**，点击作为基础的共通集合的**「复制」**按钮。
2. 在复制对话框中输入**新名称和说明**并创建（模型、工具配置、各规则设置会被继承）。
3. 打开新集合的**「编辑」**，调整以下内容：
   - 集合的**名称/说明**、**文件类型（document types）的添加与删除**。
   - 各审查项（规则）的**正文（description）**、**所需文件类型（requiredDocumentTypes）**、**使用模型**、**工具配置**。
4. 保存并发布。
5. ※若需在其他环境复现，用**「导出」**生成 JSON，在目标环境用**「导入」**复原（模型/工具配置仅当目标环境存在时才会继承）。

### 注意
- 使用过（已有审查记录）的集合**不可编辑**。调整时请复制后在新集合进行。
- **删除文件类型**时，若仍有规则引用该类型（requiredDocumentTypes），会被拒绝。请先解除相关规则的引用。
- 共通集合的编辑/删除**仅限管理员**。

---

## 2. 普通用户：使用共通检查列表进行审查

选择共通检查列表，用自己提供的扫描件执行一致性审查。

### 步骤
1. 打开**创建审查（Create Review）**页面，选择共通检查列表（例：登记类文件一致性审查）。
2. 为每个**文件类型**上传扫描件（PDF/图片）并分配到对应类型。
   - 例：抵当权設定契約証書／登記完了証／登記情報識別通知／建物登記簿謄本／本地登記簿謄本。
3. 输入**案件信息（caseData）**（JSON 格式），作为与文件比对的对象。
4. 启动审查。
5. 结果按每条规则以 **一致（pass）／不一致（fail）／无法判定（undeterminable）** 三种状态显示，父项「総合審査」汇总**综合判定**。

### 注意
- 共通检查列表**仅可查看**（编辑由管理员进行）。
- 上传文件的**文件类型**必须与集合定义的类型一致。
- 请确认案件信息中的项目（客户姓名、借款金额、利率、地址等）与文件是否一致（通过姓名去空格、金额逗号、和历↔西历等正規化后比较）。
