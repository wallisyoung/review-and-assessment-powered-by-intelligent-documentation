# 共通チェックリスト運用ガイド（簡易版）

共通チェックリスト（例：登記書類整合性審査）は、文書タイプを宣言した共有チェックリストセットです。**全ユーザーが参照**でき、**編集（作成・変更・削除）は管理者のみ**可能です。

---

## 1. 管理者：共通チェックリストの複製と調整

改修は「既存セットを複製し、新しいセットで調整する」手順で行います。

### 手順
1. **チェックリスト一覧**を開き、ベースとなる共通セットの**「複製」**ボタンを押す。
2. 複製ダイアログで**新しい名称・説明**を入力して作成（モデル・ツール設定・各ルールの設定は引き継がれます）。
3. 新しいセットの**「編集」**を開き、以下を調整する：
   - セットの**名称／説明**、**文書タイプ（document types）の追加・削除**。
   - 各審査項目（ルール）の**本文（description）**、**必要な文書タイプ（requiredDocumentTypes）**、**使用モデル**、**ツール設定**。
4. 保存して公開。
5. ※別環境で再現する場合は**「エクスポート」**で JSON を出力し、対象環境で**「インポート」**で取り込む（モデル・ツール設定は対象環境に存在する場合のみ引き継がれます）。

### 注意
- 使用済み（レビュー実績がある）セットは**編集不可**。調整時は複製して新セットで行う。
- **文書タイプの削除**時、そのタイプを参照しているルール（requiredDocumentTypes）があると拒否される。先に該当ルールの参照を解除すること。
- 共通セットの編集・削除は**管理者のみ**。

---

## 2. 一般ユーザー：共通チェックリストで審査を実施

共通チェックリストを選んで、自分の持込書類で整合性審査を実行します。

### 手順
1. **レビュー作成（Create Review）**画面を開き、共通チェックリスト（例：登記書類整合性審査）を選択。
2. 各**文書タイプ**ごとにスキャン書類（PDF／画像）をアップロードし、タイプに割り当てる。
   - 例：抵当権設定契約証書／登記完了証／登記情報識別通知／建物登記簿謄本／本地登記簿謄本。
3. **案件情報（caseData）**を入力（JSON 形式）。書類との比較対象になる。
4. 審査を開始。
5. 結果は各ルールごとに **一致（pass）／不一致（fail）／判定不能（undeterminable）** の3状態で表示され、親項目「総合審査」に**総合判定**が集約される。

### 注意
- 共通チェックリストは**参照のみ**（編集は管理者）。
- アップロード書類の**文書タイプ**は、セットが定義したタイプと一致させる必要がある。
- 案件情報の項目（顧客氏名・借入金額・金利・住所など）と書類が整合するか確認すること（氏名の空白除去・金額のカンマ・和暦↔西暦などの正規化を介して比較される）。
